# Hangulation 한글 패처

게임 한글 패처의 다운로드 전용 저장소입니다. 패처 개발 소스와 게임 원본 파일은 이 저장소에 포함하지 않습니다.

## 다운로드

[최신 배포 목록](https://github.com/edoli/Hangulation-Releases/releases)에서 게임에 맞는 `*-ko-patcher.exe`를 받으세요. 현재 배포판은 **프리릴리스**입니다.

| 게임 | 다운로드 파일 |
| --- | --- |
| Aviary Attorney | `aviary-attorney-ko-patcher.exe` |
| Cosmic Star Heroine | `cosmic-star-heroine-ko-patcher.exe` |
| of the Devil | `of-the-devil-ko-patcher.exe` |
| Ara Fell | `ara-fell-ko-patcher.exe` |

게임을 종료한 뒤 패처를 실행하고, 설치 폴더를 확인한 다음 **한국어 패치 적용**을 누르세요. 원본 상태로 되돌릴 때는 Steam의 **게임 파일 무결성 검사**를 사용하세요.

패처는 대상 파일의 SHA-256을 확인합니다. 파일이 제작 기준과 다르면 적용을 시작하지 않습니다. 지원 기준 빌드 ID와 검증 범위는 각 Release의 설명을 확인하세요.

다운로드한 파일은 Release에 첨부된 `SHA256SUMS.txt`로 확인할 수 있습니다.
